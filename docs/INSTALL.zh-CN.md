# 安装 Wink

需要 macOS 15 或更新版本。从 [官方 GitHub Releases](https://github.com/xrf9268-hue/Wink/releases/latest) 下载 DMG。

1. 打开 DMG，将 Wink 拖入“应用程序”。
2. 从“应用程序”打开 Wink，再推出 DMG。保留一份安装副本，避免给另一份构建授予权限。
3. 当前公开版本 v0.7.5 使用临时签名，尚未通过 Apple 公证。如果 macOS 因无法验证开发者而阻止打开，且你信任下载来源，在首次尝试启动后进入“系统设置 → 隐私与安全性 → 仍要打开”，然后确认“打开”。
4. 按提示授予“辅助功能”权限。Hyper 快捷键和标准 Fn+F-row 组合还需要“输入监控”。更改输入监控权限后，退出并重新打开 Wink。
5. 为一个已安装的 App 添加快捷键。按一次唤出；默认 Toggle 行为下，再按一次隐藏。

## 信任与更新

Wink 采用 [MIT 许可证](../LICENSE)。配置和使用统计保存在本机，权限及联网行为见[隐私说明](privacy.md)。

Sparkle 更新签名和 GitHub 构建来源证明不能替代 Apple Developer ID 签名或公证。当前版本可以提供签名更新，但首次安装仍可能需要手动批准；请以各版本发布说明的签名状态为准。需要核验安装包来源时，参阅[构建来源验证](../VERIFYING_RELEASES.md)。

后续版本可在 Wink 中“检查更新”。签名身份改变时，可能需要为安装的副本重新授予权限。

## 遇到问题

- 没有“仍要打开”：先尝试启动一次。受管理的 Mac 可能需要管理员批准。
- 提示已损坏或包含恶意软件：停止安装并核验来源，不要把它当成“无法验证开发者”的提示处理。
- 快捷键无响应：检查“应用程序”中这一份 Wink 的权限，更改输入监控后重启 Wink，并查看设置中的快捷键状态。
- 不需要全局关闭 Gatekeeper，也不要通过移除隔离属性安装 Wink。

Apple 的标准操作说明：[安全地在 Mac 上打开 App](https://support.apple.com/en-us/102445)。

## 卸载

退出 Wink，再将“应用程序”中的 Wink 移到废纸篓。这只删除 App，会保留本地设置和快捷键。清理本地数据前，先导出需要保留的快捷键方案。
